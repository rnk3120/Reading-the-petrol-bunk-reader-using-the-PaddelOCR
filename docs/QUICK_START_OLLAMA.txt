HOW TO USE (3 SIMPLE STEPS)
=================================================================

STEP 1: Start Ollama Service
-----------------------------
Double-click: start_ollama.bat

OR in PowerShell:
    ollama serve

(Leave this window open while processing videos)


STEP 2: Run OCR with Validation
--------------------------------
Option A - Using the helper script:
    1. Edit run_ocr_with_validation.bat
    2. Change VIDEO_PATH to your video file
    3. Double-click the script

Option B - Manual command:
    python ocr.py "C:/path/to/video.mp4" --out ./results --use-ollama


STEP 3: Check Results
----------------------
Look in the ./results folder for:
- all_frames_TIMESTAMP.csv
  → Every frame with OCR + Ollama validation
  → New columns: "Ollama_ROI_3" and "Validation_Status"

- stable_values_TIMESTAMP.csv
  → Only stable readings (unchanged for 2-3 seconds)

=================================================================
WHAT HAPPENS DURING PROCESSING
=================================================================

Every frame:
  → PaddleOCR extracts text (fast, 20 FPS)

Every 4 seconds:
  → Ollama AI validates the reading
  → If OCR made a mistake, Ollama corrects it
  → Status is logged: MATCH, CORRECTED, FILLED, or FAILED

Example output:
  [VALIDATION] Running Ollama check at 4.00s...
    ✓ OCR and Ollama agree: 345.67

  [VALIDATION] Running Ollama check at 8.00s...
    ⚠ Correction: OCR=34567 → Ollama=345.67

=================================================================
CUSTOMIZATION
=================================================================

Validate more often (every 2 seconds):
    python ocr.py video.mp4 --use-ollama --validation-interval 2.0

Validate less often (every 10 seconds):
    python ocr.py video.mp4 --use-ollama --validation-interval 10.0

Skip frames for faster processing:
    python ocr.py video.mp4 --use-ollama --frame-skip 5

Save annotated video:
    python ocr.py video.mp4 --use-ollama --save-annotated-video
