# Hardcoded Static ROIs - Quick Guide

## ✅ ROIs Are Now in the Code!

Your static ROI coordinates are now **hardcoded directly in `ocr.py`** - no external files needed!

---

## 🎯 How to Use

### For Images:
```powershell
conda activate ocr_env
cd C:\Users\niteshk\Desktop\vs\OCR

python ocr.py "C:\Users\niteshk\Desktop\OCR\reader.jpg" --mode image --out ./results --use-static-rois
```

### For Videos:
```powershell
python ocr.py "C:\Users\niteshk\Desktop\OCR_Videos\pump_reader.mp4" --out ./results --use-static-rois
```

### With All Features:
```powershell
python ocr.py "video.mp4" --out ./results --use-static-rois --use-ollama --excel
```

## 🔧 How to Edit ROI Coordinates

1. Open `ocr.py` in your editor
2. Find the `get_hardcoded_rois()` function (around line 100)
3. Edit the `STATIC_ROIS` dictionary coordinates
4. Save the file
5. Run your script - it will use the new coordinates!

---

## 📊 Three Ways to Use ROIs

| Method | Command Flag | When to Use |
|--------|-------------|-------------|
| **Auto-detect** | (none) | Different images/videos |
| **Hardcoded** | `--use-static-rois` | Same setup, no config file |
| **Config file** | `--roi-config roi_config.json` | Multiple setups |

---

## ⚡ Quick Commands

```powershell
# Use hardcoded ROIs (simplest)
python ocr.py "image.jpg" --mode image --use-static-rois

# Use hardcoded ROIs for video
python ocr.py "video.mp4" --use-static-rois

# Full featured
python ocr.py "video.mp4" --use-static-rois --use-ollama --excel

# Auto-detect (no static ROIs)
python ocr.py "video.mp4"
```
